Actúa como desarrollador web senior experto en JavaScript, Node.js y Clean Code. Crea desde cero un proyecto modular que consulte JSONPlaceholder y muestre todas las publicaciones de todos los usuarios, junto con sus comentarios.

Genera el contenido completo de todos estos archivos, sin omitir ninguno:

1. package.json
2. env.js
3. solicitudes.js
4. servicios.js
5. formateador.js
6. index.js

Requisitos del proyecto:

- Usa módulos ES de JavaScript (`import` y `export`) y configura `"type": "module"` en `package.json`.
- En `package.json`, agrega el script `"dev": "node index.js"`.
- No agregues dependencias externas.
- La URL base de la API debe ser `https://jsonplaceholder.typicode.com`.
- Usa `fetch` para las solicitudes HTTP.
- `env.js`: exporta únicamente la constante `API_BASE_URL`.
- `solicitudes.js`: exporta la función `solicitarJSON(url)`. Debe comprobar si la respuesta HTTP fue exitosa, lanzar un error que incluya el código de estado si no lo fue y devolver el JSON.
- `servicios.js`: exporta `obtenerPublicacionesConComentarios()`. Debe consultar `/posts` y `/comments`, preferiblemente en paralelo con `Promise.all`. Para cada publicación, asocia únicamente los comentarios cuyo `postId` coincida con el `id` de esa publicación. Devuelve una lista de objetos con esta estructura:
  {
    userId,
    id,
    titulo,
    cuerpo,
    comentarios: [
      { autor, texto }
    ]
  }
  Usa `comentario.email` como `autor` y `comentario.body` como `texto`.
- `formateador.js`: exporta `formatearParaConsola(publicaciones)`. Debe recibir el arreglo de publicaciones y devolver un único string legible. Para cada publicación, incluye las etiquetas `User ID`, `Post ID`, `Título`, `Cuerpo` y `Comentarios`. Para cada comentario, muestra claramente `Autor` y `Texto`.
- `index.js`: importa el servicio y el formateador, ejecuta el flujo con `.then()` y `.catch()`, imprime el resultado y muestra los errores con `console.error`. No uses `async/await` ni objetos globales exclusivos de Node.js como `process`.
- Evita el anidamiento profundo de promesas. Retorna las promesas correctamente y usa `Promise.all` para las solicitudes independientes.
- No uses `JSON.stringify` ni imprimas los objetos completos como JSON.
- Mantén una sola responsabilidad por archivo y asegúrate de que todos los nombres de funciones, imports y exports coincidan.

Entrega:
1. El árbol completo del proyecto.
2. El contenido completo de cada archivo, cada uno en su propio bloque de código y con el nombre del archivo como encabezado.
3. Una breve indicación para ejecutarlo con `npm run dev`.
4. Confirma que la salida muestra publicaciones y comentarios, incluyendo User ID, Post ID, título, cuerpo, autor y texto.
