Genera el código completo distribuido en los siguientes 5 archivos, cumpliendo estrictamente con estas reglas:

1. Principio de Responsabilidad Única (SRP): Cada archivo debe hacer una sola cosa. Separa la configuración, las peticiones HTTP, la lógica de negocio (promesas), el formateo de texto y la ejecución principal.
2. Encadenamiento de Promesas limpio: Usa `.then()` pero evita el anidamiento profundo (Promise Hell). Retorna las promesas para encadenarlas al mismo nivel. Usa `Promise.all` para las peticiones en paralelo de los comentarios.
3. Entorno agnóstico: El código debe poder ejecutarse en el navegador, así que NO incluyas objetos globales de Node.js como `process.exitCode`.

Por favor, devuélveme el código para estos archivos:

- `env.js`: Solo debe exportar la constante `API_BASE_URL` ('https://jsonplaceholder.typicode.com').

- `formateador.js`: Debe tener una función `formatearParaConsola(publicaciones)` que reciba el array de objetos y retorne un único string formateado con Título, Cuerpo y Comentarios, listo para imprimir.
- `servicios.js`: Debe tener la función `obtenerPublicacionesConComentarios()` que encadene las llamadas a `solicitarJSON` para traer el usuario 1, sus posts, y los comentarios mapeados correctamente.
- `index.js`: El punto de entrada que importe el servicio y el formateador, ejecute la promesa e imprima el resultado final o el error.
